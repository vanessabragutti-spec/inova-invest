# Agenda

Lista de horários para eventos, webinars e cronogramas do programa.

- Consumidor fornece: para cada item, o horário (HH:MM), o título curto e uma linha de detalhe (quem, duração).
- O horário vai em `texto-destaque`, com algarismos tabulares. O título vai em `texto` e o detalhe em `texto-suave`.
- Os itens são separados por fios `linha`. Não use caixas nem cores de fundo por item.
