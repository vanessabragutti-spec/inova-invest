# PostFeed

Modelo de post quadrado (1080 × 1080) para anunciar evento ou abertura de inscrições, em fundo `azul`.

- Estrutura: logo negativa no topo à esquerda, etiqueta de `acento`, título em `display` (até 3 linhas), bloco de data e formato em `texto-suave`, trapézio verde sangrando pela esquerda e assinatura em faixa branca no rodapé.
- Consumidor fornece: o título, a data, o horário e o formato. Mantenha margens de 96 px.
- Em carrossel, use este layout só no primeiro card e repita a assinatura completa, com os rótulos, no último.
- A prévia mostra o post a 40% do tamanho.
