# Assinatura

Bloco de marcas que fecha toda peça oficial, no rodapé ou no último card de um carrossel.

- A ordem é fixa: **Realização**, com Inova+Invest e ABVCAP; **Promovido por**, com o trio ApexBrasil, Ministério e Governo do Brasil; e, separada por um fio, **Parceria**, com a ACE Ventures.
- O bloco vai sempre sobre uma faixa `branco`, mesmo em peças de fundo azul. Assim o trio ApexBrasil/Governo fica na versão colorida, como a Apex exige, e a ABVCAP fica na versão que temos.
- Consumidor fornece: a altura base `--ii-h`, que é a altura da marca ApexBrasil. Ela nunca pode ser menor que `apex-min-tela` (35 px) em tela. As outras marcas não podem passar dessa altura.
- Toda peça com este bloco vai para aprovação em valida@apexbrasil.com.br.
