# Etiqueta

Rótulo curto que classifica a peça (formato, status, região). É o único lugar, junto com o botão, onde a caixa alta é permitida.

- Consumidor fornece: o texto, de uma a três palavras. Escreva em caixa normal; a classe aplica a caixa alta.
- `ii-etiqueta` (padrão, `verde-100` com texto `azul`), `--acento` (verde, para status como "Inscrições abertas"), `--azul`, `--contorno`.
- No máximo duas etiquetas por peça, acima do título, separadas dele por `space-2`.
- Não use etiqueta como título nem em frases.
