# Destaque

Número, data ou prazo que é o ponto da informação, com uma linha que explica o que ele é.

- Consumidor fornece: o número no estilo `numero`, com a unidade opcional dentro de `<em>` (vai em `texto-destaque`), e um rótulo de até duas linhas.
- A barra vertical de `acento` marca o bloco. Use de um a três destaques por peça, nunca números de enfeite.
