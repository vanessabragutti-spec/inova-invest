# Palestrante

Cartão de pessoa para eventos, agendas e posts de "quem vai falar".

- Consumidor fornece: a foto (quadrada, recortada em círculo por `radius-foto`), o nome e o cargo com a organização ("Superintendente Executiva, ABVCAP").
- Sem foto, use as iniciais sobre `azul`, como nas prévias.
- O cartão usa fundo `fundo-alt` e cantos retos (`radius-0`). Nunca use sombra.
